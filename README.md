# Jirgenson Model Canon v1.0

The Canon is the theory of the Jirgenson Management Model in machine-readable form: goals in refusal order, state and error, three zones, levers vs conditions, two forecasts, control. It is Appendix H of the book *Steer, Don't Guess* by Martin Jirgenson (2026).

**File:** [`jirgenson_canon_v1.0_en.md`](jirgenson_canon_v1.0_en.md) (plain text, Markdown headings). Free to download and share, see licence below.

## What it is for

The Canon is used together with the **Jirgenson Model Operating Prompt**, which tells a language model how to apply the Canon in a conversation. The prompt checks that the Canon is present and does not answer without it.

How to use: open a new chat (Claude, ChatGPT, Gemini or similar), attach this file together with the Operating Prompt (or put both into a project / system instructions), then describe your situation. The model asks for what it needs.

The Operating Prompt is sold on PromptBase. The full method, with examples and the reasoning behind it, is in the book: https://jirgenstorm4.gumroad.com/l/steer-dont-guess
